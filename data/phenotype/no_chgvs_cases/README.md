# HPO-Only Case Annotation Files

This directory will contain the HPO annotation files for cases without cHGVS variant records upon publication.

## Contents (to be released)

- HPO annotation files for HPO-only cases (236 cases)
- Format: one HPO identifier per line (e.g., `HP:0000153`)

## Data will be made publicly available upon publication

These files will be deposited alongside the main HPO dataset in a permanent repository (e.g., Zenodo) and linked here upon manuscript publication. The actual file names and directory layout will be disclosed at that time.
