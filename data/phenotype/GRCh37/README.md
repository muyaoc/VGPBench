# HPO Annotation Files

This directory will contain the HPO annotation files for paired HPO+VCF virtual patients upon publication.

## Contents (to be released)

- HPO annotation files for paired HPO+VCF cases (779 cases)
- Format: one HPO identifier per line (e.g., `HP:0001250`)
- Each file contains the validated HPO identifiers for one virtual patient, generated by `scripts/virtual_patients/map_phenotypes_to_hpo_improved.py`

## Data will be made publicly available upon publication

The complete HPO dataset will be deposited in a permanent repository (e.g., Zenodo) and linked here upon manuscript publication. The actual file names and directory layout will be disclosed at that time.
