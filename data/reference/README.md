# Reference Data — Master Variant Table

This directory will contain the master variant table upon publication.

## Contents (to be released)

- **`published_diagnosed_pathogenic_variants_combined.txt`** — Master variant table with 1,289 curated literature-derived cases: causal gene, cHGVS, phenotype, disease, and reference genome. This is the source table from which all virtual patients (VCF + HPO) are constructed.

## Data will be made publicly available upon publication

The master variant table will be deposited in a permanent repository (e.g., Zenodo) and linked here upon manuscript publication. Until then, this file is intentionally omitted.
